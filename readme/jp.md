# Dance Pictogram — 使い方

踊っている間、映像の横に動きのキューが流れ、次の動作が起きる少し前に何をするかを教えてくれます。
VRChat の [PyPyDance](https://pypydance.com/) 向けに作られています。

**言語:** [English](en.md) · [繁體中文](tc.md) · [简体中文](sc.md) · 日本語 · [한국어](ko.md)

---

## 1. インストール

1. [Releases](https://github.com/touma-tw/dance-pictogram/releases) から最新の
   `DancePictogram-x.y.z.zip` をダウンロードします。
2. 好きな場所に解凍します。デスクトップでも構いません。**`C:\Program Files` は避けてください** —
   アプリは楽曲データを自分と同じ場所に書き込みます。
3. `DancePictogram.exe` を実行します。

インストーラーもアカウントもキーも不要です。削除するときはフォルダごと消してください。

## 2. 楽曲をダウンロードする

アプリには楽曲データが含まれていません。**Songs** タブを開いてください。

**手っ取り早い方法** — 上部のパックボタンを押します:

| ボタン | 内容 |
|---|---|
| **Pictogram** | 矢印付きの人型イラスト。全 598 曲で 851 MB。 |
| **Real dancer** | 映像から切り抜いた実際のダンサーに、同じ矢印を重ねたもの。1632 MB。 |
| **Everything** | 両方。2244 MB。 |

そのあと **Download selected** を押します。数分かかりますが、その間もアプリは操作できます。

**選んで入れる方法** — 検索ボックスに入力して Enter を押し、欲しい曲にチェックを入れて
**Download selected**。パック全体ではなく、その曲だけがダウンロードされます。

検索は通常のキーワード(曲名・アーティスト・ジャンル・ID)に加え、条件の組み合わせにも対応します:

```
twice                 「twice」に一致するもの
artist:twice          そのアーティストのみ
mode:multi            複数のコーチから選べる曲
genre:kpop            ジャンルで絞る
installed:no          まだ入れていないもの
```

すべて導入するとパックボタンは自動的に折りたたまれます。見出しをクリックすると再び開きます。

## 3. VR での設定

**Overlay** タブに移り、大きな **Start** ボタンを押します。そのあと VRChat 内で:

- **VR distance** — キューの帯が浮かぶ距離。映像スクリーンとほぼ同じ奥行きに置くと、
  視線のピント合わせを行き来せずに済みます。
- **VR scale** — 距離とは別に、見た目の大きさを変えます。
- **Pin in room** — 頭の動きに追従させず、空間に固定します。
- **Pictogram / Real** — 表示するスタイルの切り替え。

さらに、**右手の甲**の上に小さなパネルが浮かびます。ボタンを少し見つめると押せます。
**PIN**(デスクトップに戻らずに帯を置き直す)と **STYLE** があります。

## 4. 踊っている間

アプリは VRChat のログから「どの曲か」を、スピーカーの音から「曲のどこか」を判断します。
こちらから何かを指定する必要はありません。

**VRChat を既定の場所以外にインストールしている場合**、ログが見つからず、音だけで曲を識別する
方式に切り替わります。音源が同じで振り付けだけ異なる曲は区別できません。アプリと同じ場所にある
`config.toml` を開き、`[log]` セクションを編集してください:

```toml
[log]
dir = '%USERPROFILE%\AppData\LocalLow\VRChat\VRChat'   # <- この行を変更
```

`output_log_*.txt` が置かれているフォルダーを指定します。**シングルクォートは残してください** ——
バックスラッシュがエスケープ文字として解釈されるのを防ぎます。保存後、アプリを再起動します。

**複数ダンサーの曲**ではコーチごとにレーンが表示されます。曲が始まると目の前に選択画面が出るので、
追いかけたいコーチを 2 秒間見つめてください。

**タイミングが少しずれて感じる場合。** `config.toml` の `video_lag_sec` を調整するか、
お知らせください。正の値でキューが遅く、負の値で早く出ます。
準備動作が必要なキューは、少し早めに出したほうが踊りやすいこともあります。

## 5. OBS で録画する

SteamVR のオーバーレイは VRChat の描画の上に合成されるため、VRChat 自身のカメラからは見えません。
Overlay タブで **Spout → OBS** をオンにし、OBS で **Spout2 Capture** ソースを追加して
`DancePictogram` を選んでください。VRChat のカメラソースの上に重ね、合成モードを
ストレート(非乗算済み)アルファに設定します。

## 6. うまくいかないとき

**帯が空のまま。** 何も再生されていないか、アプリが音を拾えていません。Overlay タブの
オーディオデバイスを確認してください。VRChat の音が鳴っているデバイスの
**ループバック**を選ぶ必要があります。

**違う曲が表示される。** 曲の判定は VRChat のログを読んでいます。VRChat が起動していない場合は
音による識別に切り替わりますが、音声が同じで振り付けだけ異なる曲は区別できません。

**特定の曲でキューがずれている、間違っている。** 起こり得ます —— キューは自動生成されており、
カット切り替えが速い、モーションブラーが強い、複数のダンサーが交差するといった映像では精度が落ちます。
曲の ID を添えて [issue を立ててください](https://github.com/touma-tw/dance-pictogram/issues)。
作り直した曲は以降のバッチで配信され、アプリは変更分だけを更新します。

**アップデート。** 起動時に新規・修正された曲を確認します。Songs タブに変更点が表示されるので、
**Install everything missing** を押してください。
