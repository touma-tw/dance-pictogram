# Dance Pictogram — 사용 설명서

춤추는 동안 영상 옆으로 동작 큐가 흘러가며, 각 동작이 일어나기 직전에 무엇을 할지 알려줍니다.
VRChat의 [PyPyDance](https://pypydance.com/)를 위해 만들어졌습니다.

**언어:** [English](en.md) · [繁體中文](tc.md) · [简体中文](sc.md) · [日本語](jp.md) · 한국어

---

## 1. 설치

1. [Releases](https://github.com/touma-tw/dance-pictogram/releases)에서 최신
   `DancePictogram-x.y.z.zip`을 내려받습니다.
2. 원하는 위치에 압축을 풉니다. 바탕화면도 괜찮습니다. **`C:\Program Files`는 피하세요** —
   앱이 곡 데이터를 자기 옆에 저장합니다.
3. `DancePictogram.exe`를 실행합니다.

설치 프로그램도, 계정도, 키도 필요 없습니다. 제거하려면 폴더째 삭제하면 됩니다.

## 2. 곡 내려받기

앱에는 곡 데이터가 들어 있지 않습니다. **Songs** 탭을 여세요.

**가장 빠른 방법** — 위쪽의 팩 버튼을 누릅니다:

| 버튼 | 내용 |
|---|---|
| **Pictogram** | 화살표가 붙은 그림 인물. 전체 598곡에 851 MB. |
| **Real dancer** | 영상에서 배경을 제거해 오려낸 실제 댄서에 같은 화살표를 얹은 것. 1632 MB. |
| **Everything** | 두 가지 모두. 2244 MB. |

그다음 **Download selected**를 누르세요. 몇 분 걸리며, 그동안에도 앱을 계속 쓸 수 있습니다.

**골라서 넣는 방법** — 검색창에 입력하고 Enter를 누른 뒤, 원하는 곡을 체크하고
**Download selected**를 누릅니다. 팩 전체가 아니라 그 곡들만 내려받습니다.

검색은 일반 단어(곡명, 아티스트, 장르, ID)와 조합 가능한 필터를 지원합니다:

```
twice                 "twice"와 일치하는 모든 것
artist:twice          해당 아티스트만
mode:multi            여러 코치 중에서 고를 수 있는 곡
genre:kpop            장르로 좁히기
installed:no          아직 설치하지 않은 것
```

전부 설치하고 나면 팩 버튼은 자동으로 접힙니다. 제목 줄을 누르면 다시 펼쳐집니다.

## 3. VR에서 설정하기

**Overlay** 탭으로 가서 큰 **Start** 버튼을 누르세요. 그다음 VRChat 안에서:

- **VR distance** — 큐 띠가 떠 있는 거리. 영상 스크린과 비슷한 깊이로 밀어두면
  두 곳 사이에서 눈의 초점을 다시 맞출 필요가 없습니다.
- **VR scale** — 거리와 무관하게 보이는 크기.
- **Pin in room** — 머리를 따라오지 않고 공간에 고정합니다.
- **Pictogram / Real** — 어떤 스타일을 보여줄지.

또한 **오른손 손등** 위에 작은 패널이 떠 있습니다. 버튼을 잠시 바라보면 눌립니다 —
VRChat이 컨트롤러를 점유하고 있어서 시선이 유일한 입력 수단입니다.
**PIN**(VR을 벗지 않고 띠를 다시 배치)과 **STYLE**이 있습니다.

## 4. 춤추는 동안

앱은 VRChat 로그를 읽어 어떤 곡인지 알아내고, 스피커 소리를 들어 곡의 어느 지점인지 판단합니다.
사용자가 따로 알려줄 것은 없습니다.

**여러 명이 추는 곡**은 코치마다 레인이 하나씩 표시됩니다. 곡이 시작되면 눈앞에 선택 화면이 나타나니,
따라가고 싶은 코치를 2초 동안 바라보세요.

**타이밍이 조금 어긋나 보인다면.** `config.toml`의 `video_lag_sec`을 조정하거나 알려주세요.
양수면 큐가 늦게, 음수면 일찍 나옵니다. 준비 동작이 필요한 큐는 조금 일찍 나오는 편이 나을 수 있습니다.

## 5. OBS로 녹화하기

SteamVR 오버레이는 VRChat 화면 위에 합성되기 때문에, VRChat 자체 카메라로는 이 띠가 보이지 않습니다.
Overlay 탭에서 **Spout → OBS**를 켠 뒤, OBS에서 **Spout2 Capture** 소스를 추가하고
`DancePictogram`을 선택하세요. VRChat 카메라 소스 위에 겹치고, 합성 모드를
스트레이트(비사전곱) 알파로 설정합니다.

## 6. 문제가 있을 때

**띠가 비어 있습니다.** 재생 중인 것이 없거나, 앱이 소리를 듣지 못하고 있습니다.
Overlay 탭의 오디오 장치를 확인하세요. VRChat 소리가 나오는 장치의 **루프백**이어야 합니다.

**다른 곡이 표시됩니다.** 곡 판별은 VRChat 로그를 읽습니다. VRChat이 실행 중이 아니면
소리로 식별하는 방식으로 대체되는데, 음원이 같고 안무만 다른 곡은 구분할 수 없습니다.

**특정 곡의 큐가 틀리거나 타이밍이 어긋납니다.** 있을 수 있는 일입니다 — 큐는 자동으로 생성되며,
컷 전환이 빠르거나 모션 블러가 심하거나 여러 댄서가 교차하는 영상에서는 품질이 떨어집니다.
곡 ID를 적어 [이슈를 남겨주세요](https://github.com/touma-tw/dance-pictogram/issues).
다시 생성된 곡은 이후 배치로 배포되며, 앱은 바뀐 부분만 업데이트합니다.

**업데이트.** 앱은 시작할 때 새로 추가되거나 수정된 곡이 있는지 확인합니다.
Songs 탭에 변경된 항목이 표시되니 **Install everything missing**을 누르세요.
